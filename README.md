# Spotify

Analyse des Artistes les Plus Écoutés sur Spotify
Dashboard Power BI – Analyse des tendances musicales mondiales (2024-2026)


##Contexte et Objectifs
Ce dashboard a été conçu pour analyser les tendances d’écoute des artistes sur Spotify à l’échelle mondiale, en croisant :

- La répartition géographique des streams (par continent/région).
- Les genres musicaux les plus populaires.
- Les artistes les plus streamés.
- Le type de streams (Solo, Lead, Feature).

Public cible :

- Équipes marketing des labels musicaux (pour cibler les campagnes).
- Artistes et managers (pour identifier les tendances et opportunités).
- Analystes data (pour benchmarker les performances).
- Investisseurs dans l’industrie musicale (pour évaluer les marchés porteurs).

##Objectif principal :
Identifier les segments porteurs (genres, régions, types de streams) et les artistes dominants pour orienter les stratégies de promotion et de contenu.

##Les insights clés

1. Les Lead Streams dominent l’écosystème musical

6,07M streams (48,28% du total) sont des Lead Streams (morceaux principaux).
Solo Streams représentent 33,1% (4,16M), tandis que les Feature Streams sont sous-représentés (18,62%).
→ Opportunité : Les labels devraient encourager les collaborations (features) pour diversifier les écoutes.

2. Hip-Hop et Pop : les genres incontournables

Hip-Hop (2M+ streams) et Pop (1,8M+) représentent 35% des écoutes totales.
Reggaeton et Latin (900K+ streams) sont en forte croissance.
→ Stratégie : Investir dans des playlists thématiques (ex : "Hip-Hop Français", "Reggaeton Hits") pour capter l’audience.


4. Drake et Taylor Swift : les géants incontestés

Drake domine avec 120K+ streams, suivi de près par Taylor Swift (110K+).
Bad Bunny et The Weeknd complètent le top 4.
→ Collaboration : Les marques et labels devraient associer ces artistes à des campagnes pour maximiser l’impact.

5. Disparités de Genre dans l'Industrie Musicale

Les artistes femmes sont surreprésentées dans le genre Pop, mais sous-représentées dans les autres genres (Hip-Hop, Rock, EDM).
Seulement 20% des artistes streamés sont des femmes à l'échelle mondiale, avec des disparités marquées selon les pays (ex : l'Europe en général)
